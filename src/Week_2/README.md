# Java Internship Practice

## About This Repository
This repository contains Java programs and practice problems that I worked on as part of my week second of my internship. It focuses on improving my Core Java programming skills, problem-solving ability, Array problems and understanding of object-oriented programming.

## Topics Covered

### 1. Java Programming Problems
- Largest Element in an Array
- Smallest Element in an Array
- Second Largest Element in an Array
- Reverse an Array
- Remove Duplicates from a Sorted Array
- Two Sum Problem
- Best Time to Buy and Sell Stock
- Move zeros
- Array is Sorted or not
- Rotate an array by given places

### 2. Java Concepts
- Arrays and Array Operations
- Loops and Conditional Statements
- Methods
- User Input Using Scanner
- Switch Case
- Object-Oriented Programming Basics

### 3. Mini Project
**Banking Application**

Features:
- Account Creation
- Deposit Money
- Withdraw Money
- Balance Enquiry
- Menu-Driven Program Using Switch Case
