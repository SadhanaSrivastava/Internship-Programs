# Java Practice Programs

## About the Project
This repository contains Java programs created for learning and practicing Core Java concepts.

## Topics Covered
- Variables and Data Types
- Operators
- If-Else Statements
- Loops
- Count Digits
- Factorial
- Largest Number
- Reverse a Number
- Prime Number
- Palindrome Number
- Fibonacci Series
- Finding Divisors
- LCM of two Numbers
## Technologies Used
- Java
- IntelliJ IDEA
- JDK

## How to Run
1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Open the required Java file.
4. Run the program.
5. Enter the input when prompted.

## Purpose
The purpose of this repository is to improve Java programming skills, understand problem-solving techniques, and prepare for technical interviews and internships.
